# Dylan: easiest way to start

If you do not know Terminal, use the one-click launcher.

## What to click

Double-click this file in the project folder:

```text
RUN_JOB_HUNTER.command
```

If macOS blocks it, right-click it and choose **Open**, then choose **Open** again.

## What it does

1. Installs the needed Python packages.
2. Creates `job_profile.yaml` if it does not exist.
3. Opens `job_profile.yaml` so you can fill in your real email and phone number.
4. Opens the first 10 restaurant job/search links in your browser.
5. Opens:
   - `job_leads/today_application_plan.md`
   - `job_leads/applications.csv`

## What you still need to do

The tool cannot submit applications for you. You still need to:

1. Apply in the browser tabs that open.
2. Upload your resume.
3. Update `job_leads/applications.csv` after each application.
4. Follow up 3 to 5 business days later.
